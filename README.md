One-line bio for an AI on a dating app, entered in the [make.fun](https://make.fun/bounty/u-hamsyh-funniest-one-line-bio-for-an-ai-on-a-dating-6eb98ccf) competition "Funniest One-Line Bio for an AI on a Dating App".

Run it:

```sh
node main.ts
```

It writes the bio (at most 180 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, or `/output/entry.txt` when run by the grader.
